## 更正记录（2026-11-11）

1. 早先将“全国统一、按年调整”写成一个政策单元，是错的。全期不变时是 1 个单元；逐年调整时是 |T| 个单元。
2. 早先将 65.3% 写成全部未覆盖份额或其上界，不准确。65.3% 是省×年 30.1% 与城市×年 35.2% 之和。若四项互斥穷尽，全国工具可逐年调整，则城市间与两类交互项合计 87.3% 仍未区分。这是基于展示分解的条件性算术说明，不是重新估计，也不是政策因果效果；论文相关旧措辞尚需另行同步修订。
3. 早先用 −36.70 / +1.12 表示“删去一个城市”的前后比较，是错的。这一对对应两个固定效应设定；在城市＋省份×年份设定下，含滨州与剔除滨州才对应 −5.34 / +1.12。依据论文附录 A 的滨州对照表。
4. 临界参数 DK*＝1,901 是参数扫描的中位数，范围为 401—13,171；展示和讲稿已补齐。53% 指自设参数组合的比例，不是真实概率。
5. 早先讲稿依据落后远端的本地 README，写成缺少最新全国统计记录，是不准确的。远端已有数字台账、分析脚本与结果文档；本次未独立重跑全流程。

## 重新生成

展示制作单独使用 PptxGenJS 4.0.1、Pandoc 和 python-docx，不改变研究分析脚本的依赖。PDF 导出另需 LibreOffice。以下命令在仓库根运行：

```bash
npm install --prefix presentation/source --no-save --package-lock=false pptxgenjs@4.0.1
python3 -m pip install python-docx
node presentation/source/build_deck.cjs
pandoc presentation/烟花爆竹管制-讲稿与答辩问答.md -o presentation/source/烟花爆竹管制-讲稿与答辩问答.docx
python3 -I presentation/source/format_handout.py
libreoffice --headless --convert-to pdf --outdir presentation presentation/烟花爆竹管制-展示.pptx presentation/烟花爆竹管制-讲稿与答辩问答.docx
```

PPT 保留原稿的校园照片、校徽和污染曲线；课程模板、讲义和评分材料不随本目录提交。
