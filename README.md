# 烟花爆竹管制与空气质量

**课程**：公共财政学（2026 年秋）
**选题场次**：第 1 场，外部性与公共品
**小组**：五人（阿克苏、丹东 ×2、武汉、贵阳）

**一句话研究问题**：燃放其实已有价格工具——消费税对税目"鞭炮、焰火"按销售额征收 15%，在生产环节缴纳——但地方政府普遍改用直接约束燃放**时间与地点**的禁放与限放。为什么已有的价格工具没有被校准到边际损害？这两类工具的效果与代价各是什么，选择取决于什么条件？

> **论文终稿位置：`docs/论文正文.md`**（摘要 + 九节 + 附录 A/B/C）。本文件是仓库总览与复现说明。

**主线一句话**：价格工具（消费税"鞭炮、焰火"15%，1994 年起征、三十余年未调整）在城市与时间两个维度上的**分辨率都是零**，而损害恰恰在这两个维度上变化最大；因此问题不在税率，在**工具形式**。

**因果识别降为"做过并完整报告为什么分离不出来"**，不承担主线。这不是退让：`docs/结果-第一层估计.md` 的三轮独立复核证明，零结果不是管线 bug；而"能做出 t = 2.0–3.5 的干净结果、但安慰剂「日」全线失败"这一事实，本身是论文的方法论贡献。

## 三、怎么跑代码

### 环境

```bash
python3 --version        # 需要 3.8 以上
pip install -r requirements.txt
```

只需 `numpy` 与 `matplotlib`，且**仅绘图用到**。数据下载、面板构建、覆盖率诊断、政策合并都只用标准库。

### 运行顺序

```bash
# 1. 下载原始数据（约 20 分钟 → data/raw/，180 个文件、73 MB）
python3 -u scripts/download_aqi.py

# 2. 构建面板（约 10 秒 → data/panel_cityday.csv 等）
python3 -I scripts/build_panel.py

# 3. 覆盖率诊断（可选，约 3 秒 → data/coverage_city_year.csv）
python3 -I scripts/check_coverage.py

# 4. 并入政策变量（需先填 policy/policy.csv）
python3 -I scripts/merge_policy.py

# 5. 折叠为城市 × 春节年份（→ data/panel_cityyear.csv，第一层估计的输入）
python3 -I scripts/collapse_panel.py

# 6. 校验城市→省份映射（改动 data/city_province.csv 后必跑）
python3 -I scripts/check_province_map.py

# 7. 第一层估计：事件路径 + DCDH 式逐期估计 + TWFE
python3 -I scripts/run_did.py --min-year 2021 --exclude-city 滨州   # 主估计（只含已核实单位）
python3 -I scripts/run_did.py --same-province                  # 同省对照
python3 -I scripts/run_did.py --prov-year-fe                    # 省份×年份固定效应
python3 -I scripts/run_did.py --outcome pm25_base               # 安慰剂结果变量

# 8. 【最重要的一张诊断表】安慰剂「日」扫描
python3 -I scripts/placebo_days.py --province 河南 --treat-year 2023
python3 -I scripts/placebo_days.py --province 山西 --treat-year 2026 --control all

# 9. 精确随机化推断（现只有河南可做：5/17，穷举 6188 种分配）
python3 -I scripts/rand_inference.py --province 河南 --year 2023
python3 -I scripts/rand_inference.py --province 河南 --year 2023 --placebo-year 2022

# 10. 重绘三张图（可选 → figs/）
python3 -I scripts/observed_damage.py --write
python3 scripts/make_figs.py --data-dir data --outdir figs
```

**数据文件不入库**（`.gitignore` 已排除），因此全新克隆后按上面第 1—2 步即可复现全部数据。
**手工维护、必须入库的输入**只有三个：`policy/policy.csv`、`data/enforcement.csv`、`data/city_province.csv`。

### 各脚本干什么

| 脚本 | 作用 | 输出 |
|---|---|---|
| `download_aqi.py` | 下载春节窗口的原始单日文件并归档；支持跳过已有文件、断点续跑 | `data/raw/` |
| `build_panel.py` | 从本地归档构建城市 × 日面板与聚焦城市逐小时长表 | `data/panel_cityday.csv`、`data/panel_hourly_focus.csv` |
| `check_coverage.py` | 诊断各年份观测数下滑的成因，判断平衡面板是否可行 | `data/coverage_city_year.csv` |
| `merge_policy.py` | 把政策时间线展开为城市 × 日的政策状态并入面板；**逐行校验字段数** | `data/panel_with_policy.csv` |
| `collapse_panel.py` | 折叠为城市 × 春节年份；产出 `pm25_d1`（主口径）、`pm25_base`（安慰剂）、机制列 | `data/panel_cityyear.csv` |
| `check_province_map.py` | 校验城市→省份映射：覆盖面、列序分段性、**省会错配**、与省级展开表一致 | stdout（失败返回非零） |
| `run_did.py` | 第一层估计：按批次的事件路径 + DCDH 式逐期估计 + TWFE（可加省份×年份固定效应）；同时报**有效聚类数** | `data/did_results.csv` |
| `placebo_days.py` | **安慰剂「日」扫描**：把结果变量换成窗口内每一天跑同一 DID。本项目最有说服力的诊断 | `data/placebo_days.csv` |
| `rand_inference.py` | 精确随机化推断；组合数 ≤30 万时穷举，否则抽样；`--placebo-year` 测检验自身假阳性率 | `data/rand_inference.csv` |
| `make_figs.py` | 生成三张配图（PDF + PNG + 灰度版） | `figs/` |

`make_figs.py` 会优先使用本机安装的 SciPilot 出图技能（期刊样式、视觉自检、灰度预览）；**若未安装则自动退回内置的 matplotlib 样式，不会报错**。可用 `SCIPILOT_SKILL` 环境变量指定该技能的路径。

## 四、第一批结果

**除夕到初一的日均浓度（平衡面板 308 城，12 年平均，单位 μg m⁻³）**

| 相对日 | PM2.5 | SO₂ | NO₂ | O₃（日最大） |
|---|---|---|---|---|
| 除夕前 7 日 | 56.4 | 17.3 | 31.7 | 71.4 |
| 除夕 | 60.2 | 18.1 | 20.3 | 83.2 |
| **正月初一** | **101.7** | **24.9** | 19.9 | 83.0 |
| 正月初七 | 42.4 | 14.5 | 20.0 | 79.4 |

**三条可以直接用的结论**

1. **尖峰在正月初一，不在除夕。** 燃放最密集的是除夕深夜跨零点至初一凌晨，按日历日切分大部分落于初一。凡以日均值为结果变量，主口径应用初一（`rel_day = +1`）。
2. **机制证据。** SO₂ 与 PM2.5 同步抬升，而 NO₂ 反向下降约 37%、O₃ 平坦且在正月初一无跳变。⚠️ **表述要准**（见 `docs/文献综述.md` §四）：NO₂ 的下降**本身就是假期停产停驶的效应**（Jiang et al. 2015 报告假期 NO −54%），它不能单独证明"没有交通源"。真正的论证是**方向相反**——若尖峰由交通驱动，NO₂ 应同向上升；它反而下降，说明**尖峰不是交通驱动的**。SO₂ 与 PM2.5 同向上升则指向含硫的燃放。
3. **跨城市差异极大，但不能由扩散条件解释。** 308 城中"初一／基线"倍数与基线浓度相关 r = −0.21，绝对增量相关 r = +0.24。差异留给政策变量去解释——这正是 DiD 要做的事。

### 第一层的识别诊断（**结论是负面的，必须如实报告**）

| 设定 | β | SE（CR1） | SE（含 `(N−1)/(N−K)`） | **有效聚类数** |
|---|---|---|---|---|
| 城市 + 年份 | −42.60 | 9.52 | 10.44 | **306** |
| **城市 + 省份×年份** | **+10.80** | **18.77** | 21.7–21.9 | **17** |

**符号翻转、置信区间覆盖 0。** 而"有效聚类数 17"说明：省份×年份设定下**只有河南那 17 个城市**的残差化处理变量非零，另外 289 城对 β 与标准误的贡献**都是 0**。

**决定性证据是「安慰剂日」扫描**——把结果变量换成窗口内每一个相对日，跑同一个 DID：

| rel_day | −6 | −4 | **+1（正月初一）** | +3 | +6 |
|---|---|---|---|---|---|
| 河南（同省对照）t | **+2.38** | **−2.60** | **−0.56** | **+3.21** | **−3.15** |
| 山西（全国对照）t | −3.54(−7) | **−7.06** | **+1.73** | −5.69(+3) | **+3.76** |

**"效应"出现在与燃放无关的日子上，真正的燃放日反而不显著**；山西更极端，"效应"全在除夕之前一周（|t| 达 7）。**这个估计量对燃放日没有亲和性**——它测的是城市/省份层面春节前后的整体走位。

另两条：**精确随机化推断不拒绝随机分配**（河南 5/17，穷举 C(17,5)=6188，观测值 −26.20，双侧 **p = 0.184**；8 次无政策变动转移的 KS 检验确认检验本身是校准的）；**量级先验不允许 30–50 的效应**（全国尖峰增量均值 +40.0、**中位数仅 24.8**，削减 30–50 等于消灭中位城市尖峰的 121%–201%）。

> ⚠️ **此处早先写过一个说法，已撤回**："同省对照把安慰剂从 ±46 压到 ±7，是本次分析最重要的正面发现"。**那是 n=1 个前置期的运气。** 让河南合法地多拿一个前置期后，第二个前置期是 −25.50——**与要估的效应 −26.20 一样大**。同省对照只降低安慰剂的**量级**，**没有建立平行趋势**。

**方向仍然明确**：要**市级变异 + 同省对照**，不要省级统一变异。完整诊断、功率测算、采集目标与三轮独立复核记录见 **`docs/结果-第一层估计.md`**。

## 六、必须知道的九个坑

1. **数据是 UTF-8，不要用 GBK 转码**——转码会把中文列名变成乱码。
2. **地区行署城市的名称是地区名**：数据里是「阿克苏地区」，不是「阿克苏市」。
3. **南疆城市的 AQI 与 PM10 受沙尘污染**，不能作结果变量；对南疆各市必须用 PM2.5。
4. **尖峰日在正月初一（`rel_day = +1`）**，用除夕（0）会取到被稀释的日均值。
5. **`policy.csv` 的字段内若含逗号，必须用双引号括起来**，否则整行静默错位且不报错（示例文件里曾错 3 行，把政府网站的 URL 读成了"发文主体"）。尽量用顿号代替；填完运行 `merge_policy.py` 看有没有 `!!`。
6. **五个家乡城市在样本期内都没有政策切换，全部是对照单位**——填完 38 城也不会产生识别变异。
7. **城市没有省份归属时，同省对照会静默退化为全体对照**——不报错，只是结果悄悄变回被污染的那一版。新增城市后必跑 `check_province_map.py`，它会明确列出缺失的城市。（这条是新加的：`--same-province` 此前只对河南和山西真正生效。）
8. **不要用"小标准误"论证可信。** 城市+年份固定效应给出 β = −42.60、SE = 9.52（t = 4.5），看起来很强；加上省份×年份固定效应就变成 +10.80、SE = 18.77，而且**有效聚类数只有 17**（另外 289 城的残差化处理变量恒为 0，什么都没贡献）。**设定错了，标准误照样小。**
9. **任何政策效应都必须过「安慰剂日」这一关。** 把结果变量换成春节窗口内的其他日子跑同一个 DID。若别的日子也显著，说明估计量测的是春节前后的整体走位，不是燃放。**本项目的"显著结果"全部栽在这一关**（河南初一 t = −0.56 不显著，而 −6/+3/+6 显著；山西初一无显著、−7 到 −1 的 |t| 达 3–7）。这是本项目**唯一不能省的稳健性检验**。
