\section{第一层因果识别的完整诊断}\label{app:identification}

\textbf{本附录的目的不是报告一个估计，而是报告为什么报告不出一个估计。} 正文第~\ref{sec:identification}~节给出三条诊断与结论；本附录给出全部数字、复现命令与自我更正记录。凡本附录中的数字，均可由仓库内脚本复现；凡不能复现的，已显式标出。

设定如下。处理变量为 \texttt{ban}（政策类型 $=$ 禁放）。结果变量主口径为初一日均 \pmm{2.5}，备查口径包括春节窗口均值、尖峰倍数、尖峰增量，并以节前基线作安慰剂结果变量。估计量为允许处理逆转的 de Chaisemartin--D'Haultf\oe uille 型逐期估计（自实现），TWFE 作对照。多向固定效应用交替投影实现，标准误为 CR1 聚类。

\textbf{三条必须先说明的设定限制：}

\begin{enumerate}
  \item \textbf{样本期内没有任何一次“限放 $\rightarrow$ 禁放”的切换。} 唯一一次是武汉 2006$\rightarrow$2013，在样本期之前。因此类型这一维只能识别\textbf{放松}的效果，收紧方向的变异只存在于地理范围维。
  \item \textbf{路径符号}：脚本打印的事件路径是原始差（处理组变化减对照组变化）。批次为“退出处理”时，\textbf{正值 $=$ 放开后相对对照上升}。
  \item \texttt{scope1} 与 \texttt{full\_ban} \textbf{不是两个独立口径}。二者对本次两个批次的切换事件输出\textbf{逐字节相同}，因此此前宣称的“两套口径符号应一致”是一次\textbf{空的交叉验证}。这一点保留在附录中，是因为它属于“看起来做了、其实没做”的检验，值得作为一个警示。
\end{enumerate}

\begin{quote}
\textbf{一处已撤回的说法。} 本分析早先写“同省对照把安慰剂从 $\pm 46$ 压到 $\pm 7$，是本轮最重要的正面发现”。\textbf{该说法建立在 $n=1$ 个前置期上，不成立。} 那个 $\pm 7$ 只用了 2021$\rightarrow$2022 一个前置期；让河南合法地多取一个前置期后，第二个前置期是 \textbf{$-25.50$，与要估的效应 $-26.20$ 一样大}。

一个可能的辩解是：2020 年春节初一为 2020-01-25，是武汉封城后第二天，该转移被新冠污染、不可用。\textbf{即便接受这个辩解，也只剩一个可用前置期——无论如何都不足以宣称平行趋势成立。}
\end{quote}

\textbf{两个被否掉的改进方向，也一并记录：}

\begin{itemize}
  \item 改用尖峰增量或尖峰倍数\textbf{不会}变好。全样本 $\Delta$(初一) 与 $\Delta$(基线) 的相关仅 $r=+0.098$，两者相减是加方差而非消方差（$\operatorname{Var}(\Delta d_1)+\operatorname{Var}(\Delta \text{base})-2\operatorname{Cov}=7627.8\approx\operatorname{Var}(\Delta\text{increment})=7627.9$）。安慰剂从 $-46.22$ 恶化到 $-92.69$，标准化后仍恶化约一倍（$-0.548$ SD $\rightarrow$ $-1.061$ SD），不是尺度假象。
  \item 用初六、初七作窗内参照日（河南 2023 限放允许“除夕至初五”，初六初七在两种制度下都禁放）\textbf{实测更差}：$\sigma$ 从 84.4 升到 90.0，河南随机化 $p$ 从 0.184 升到 0.221。
\end{itemize}

第二条的推论比它本身重要：\textbf{差分只在噪声属于“城市-年份水平”时才有效；它无效，说明主导噪声是初一的当日气象。} 这正是 ERA5 气象匹配之所以是必需项而非锦上添花的原因。

\subsection{精确随机化推断}

\textbf{校准性检查必须换一种论证。} 早先的写法是“假切换期 $p=0.85$，说明检验是校准的”——\textbf{这个理由在逻辑上不成立}：校准的检验在零假设下 $p$ 值服从 $U(0,1)$，观察到 0.85 与观察到 0.15 同样可能。正确的检查是对河南 8 次\textbf{无政策变动}的转移逐次跑同一检验，得 $p=0.043$、$0.173$、$0.447$、$0.516$、$0.587$、$0.850$、$0.929$、$0.999$，\textbf{KS 距离 0.225}（$n=8$ 的 5\% 临界值约 0.457，不拒绝）。\textbf{校准性未被推翻，但依据换成了这一条。}

零分布的标准差在不同转移之间从 19.4 波动到 58.7（2.6 倍）。因此“观测值位于 $-1.35$ SD”是 2023 年特有的刻度；按典型年份（sd $\approx 44$），同一个 $-26.20$ 只有约 $-0.6$ SD。

\textbf{边界}：本检验回答的是“哪几个城市改了政策”相对于省内随机分配是否罕见，\textbf{它不是因果零假设下的检验}——政策内生正是主要担忧。它真正有价值的产出是\textbf{噪声尺度}（零分布标准差），而不是那个 $p$ 值。

\subsection{结构性限制：省级切换是最难识别的变异}

山西全部面板城市在 2026 年退出处理。三条彼此独立的原因令其不可识别：

\begin{enumerate}
  \item \textbf{省内没有对照。} 同省对照库为空——这不是代码缺陷，而是省级通告一夜之间改变全省所有地级市的必然结果。
  \item \textbf{省份 $\times$ 年份固定效应将其整体吸收。} 全省同年统一切换 $\Rightarrow$ 处理变异与省份 $\times$ 年份虚拟变量完全共线，对 $\beta$ 的贡献恒等于零（实测：残差化处理变量 $\max|dd|=2.5\times10^{-32}$；全样本 $\beta$ 与河南 17 城 $\beta$ 六位小数完全相等）。
  \item \textbf{有效处理聚类数是 1，不是 10。} 这些城市来自同一个省政府的同一个决定，\textbf{它们是 1 个处理单位}。城市层聚类给 SE $=14.8$（$t=3.54$），省级聚类给 SE $=1.38$（$t=37.9$，荒谬）。\textbf{在这个设计里任何标准误公式都失效}，因为它们都要假装存在多个独立处理单位。
\end{enumerate}

\textbf{补充证据：山西 2026 放开 vs.\ 邻省的三重差分}得 $+52.2$（$t=3.54$），置换 $p<0.001$——看上去正是审稿人想要的方向与量级。但\textbf{这个差在正常年份本来就很大}：

\begin{quote}
\textbf{更正：$\sigma$ 是 35.3，不是 46。}

早先记录的“$\Delta$(初一) 的省内标准差 $\approx 46$”是错的。正确值 35.3（直接算河南 17 城 $\Delta$ 的总体标准差 $=35.335$，与从零分布反推的 35.33 吻合）。

\textbf{错因}：有限总体校正时只算了两个均值各自的方差，\textbf{漏掉 $-2\operatorname{Cov}$ 项}——5 个处理城与 12 个对照城的均值之和被总数锁死，二者负相关。正确公式为
\[
\operatorname{Var}(\text{stat})=\frac{S^2N^2}{(N-1)\,k\,(N-k)},\qquad N=17,\ k=5\ \Rightarrow\ \mathrm{sd}(\text{stat})=0.5487\,S.
\]

这个更正的方向是“对自己过于悲观”。\textbf{但不能据此把采集目标降到 $K\approx10$}：$\sigma$ 本身在转移之间波动 3 倍（35—107），而 35.3 恰好是最有利的那一年——也正是用于估计的那一年。\textbf{规划要用中心值 $\sigma\approx70$。}
\end{quote}

\textbf{功效计算。} 设计为“同省对照 $+$ 省份 $\times$ 年份固定效应”，$\mathrm{SE}\approx\sigma\sqrt{1/K+1/M}$（$K$ 为处理城数，$M$ 为同省对照城数），80\% 功效的最小可检测效应 $\mathrm{MDE}\approx2.8\,\mathrm{SE}$。待检测量级取 43。

\subsection{本附录的小结：哪些数字可以引用}

\textbf{可以引用的：}

\begin{itemize}
  \item 两个批次的构成与有效处理单位数（5 与 1）；
  \item 安慰剂“日”扫描的方向性结论（显著性出现在非燃放日）；
  \item 两个固定效应设定下的 $\beta$（$-42.60$ 与 $+10.80$）\textbf{及其有效聚类数（306 与 17）}；
  \item 随机化推断的 $p$ 值（0.1836）\textbf{及其“不是因果零假设下的检验”这一边界}；
  \item $\sigma=35.3$ 与跨转移范围 35—107；
  \item 三轮复核的一致性。
\end{itemize}

\textbf{不可以引用的：}

\begin{itemize}
  \item 任何单一的因果效应点估计。\textbf{本文不报告禁放效应的大小。}
  \item $-42.60$ 的 $t$ 值。它配上 9.52 的标准误看上去是 $t=-4.5$ 的漂亮结果，\textbf{而它是假的}。
  \item 三重差分的 $+52.2$ 或 $+43.9$。它们的方向与量级都“正确”，但安慰剂全线失败；只报它们等于选择性报告。
\end{itemize}

\begin{quote}
\textbf{最后一条纪律。} 本次复核已证明：这份数据\textbf{能}做出 $t=2.0$—$3.5$、方向“正确”、看起来干净的显著结果（全国对照三重差分 $+43.9$、山西 vs.\ 邻省 $+52.2$）。\textbf{只报主设定会得到“不显著”，只报全国对照会得到“显著”——两者都必须报，并说明为什么后者不可信。}
\end{quote}
