# 参考文献核对表

**日期**：2026-10-16
**课程要求**：参考文献**限于优质的中英文期刊**（课程大纲）。
**口径**：因此本表分两部分——**期刊文献进参考文献表**；**政府文件、国家标准、法律法规则走脚注**（它们不是期刊文献，混进参考文献会违反要求）。

**核实方法**：英文文献经 **Crossref API**（按 DOI 或书目查询）取权威元数据，逐条记 DOI；中文文献由独立核查完成（见 §六）。

**可重复核验**：`python3 -I scripts/check_refs.py` —— 从本文件抽取全部 DOI，逐条到 Crossref 取权威元数据；Crossref 未收录的再用 doi.org 判断是否已注册。

**2026-10-17 核验结果：16 条全部通过。** 12 条 Crossref 权威核实（作者/题名/刊名/卷期页逐年可查），4 条为中文期刊 DOI——**Crossref 未收录，但 doi.org 返回 302，即已注册、DOI 有效**，其卷期页须到期刊页核对。
⚠️ 判据要点：**doi.org 对已注册 DOI 返回 301/302**；跟随重定向后拿到的状态是**出版社站点**的状态（可能 500/403），**与 DOI 是否存在无关**。

### 这一轮又更正了四处（我的记录 vs 实际）

1. **A1 题名**：我记作"PM2.5短期暴露与我国居民每日死亡的关系"，**实际题名是《PM2.5短期暴露对我国死亡和急诊量影响的Meta分析》**——该文同时合并了急诊量，不只是死亡。**引用须用实际题名。**
2. **A3 区间**：`13.94–677.10 万元` 是**空气污染领域**的区间；**总体区间是 13.94–808.99 万元、总体中位数 196.22 万元**。参数表里用的是空气污染口径，标注正确，但并列引用时不要混。
3. **A4 作者**：**王金南是第 6 作者，不是第 2**。著录应为"於方, 过孝民, 张衍燊, 等"。
4. **B5 的"查不到"**：Croteau 那条**存在且 Crossref 可查**，是我检索式写错——**"查不到"不等于"不存在"**，这次是我自己犯了这条。
